# 👑 群管理员识别 插件使用文档

> 让 LLM 知道谁在群里**说了算**：自动识别 bot管理员、群主、管理员，并在对话中注入对应提示词，还能通过工具函数查询身份。

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🧠 智能注入 | LLM 请求时按身份等级 `bot管理员 > 群主 > 管理员 > 普通成员` 自动添加身份提示词（可自定义模板） |
| 💾 缓存机制 | 缓存群内管理员/群主列表，避免频繁请求 API |
| 🚦 黑白名单 | 与今日老婆插件同款黑白名单逻辑，按群启用/禁用 |
| 🔧 LLM 工具 | 提供 `get_user_role_in_chat`、`get_chat_admins_and_owners` 工具函数 |
| 🔄 手动刷新 | 支持 `/刷新管理员缓存` 命令更新缓存（仅管理员可用） |

---

## ⚙️ 配置项（WebUI 可调）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `黑白名单` | list | `["all"]` | 群禁用/启用名单，规则见下方说明 |
| `bot管理员提示词` | text | `用户「{昵称}」是bot管理员...` | bot管理员身份注入的提示词模板 |
| `群主提示词` | text | `用户「{昵称}」是群主...` | 群主身份注入的提示词模板，`{昵称}` 会被替换为用户名 |
| `管理员提示词` | text | `用户「{昵称}」是管理员...` | 管理员身份注入的提示词模板 |
| `普通成员提示词` | text | 空 | 普通成员身份注入的提示词模板，**留空则不注入** |

**黑白名单规则：**

- `all` 或 `*`：代表所有群。
- `/` 开头 + 群号：禁用该群，优先检测。
- 示例：
  - `all,/123456`：允许所有群，但禁用 123456 群。
  - `123456,234567`：仅允许这两个群。

> 💡 修改配置后**立即生效**，无需重启机器人。
> 💡 各级提示词模板均可留空，留空则该身份不注入任何提示词。

## 📱 命令用法

### `/刷新管理员缓存 [all]`

- **无参数**：刷新**当前群**的管理员/群主缓存（需在群聊中使用）。
- **`all`**：刷新**所有已缓存群**（可在私聊使用）。

**示例：**
```
/刷新管理员缓存          # 刷新当前群
/刷新管理员缓存 all      # 刷新全部
```

> ⚠️ 仅机器人管理员可使用此命令；被黑白名单禁用的群无法刷新。

## 🛠️ LLM 工具函数（供 AI 调用）

插件提供了两个工具函数，LLM 可在对话中自动调用：

### 1️⃣ `get_user_role_in_chat`
- **作用**：获取发送者在当前群的身份（bot管理员 > 群主 > 管理员 > 普通成员）。
- **返回示例**：`用户「小明(123456)」的群内身份为：群主`

### 2️⃣ `get_chat_admins_and_owners`
- **作用**：获取当前群所有群主和管理员的字典（ID → 身份）。
- **返回示例**：`{"123456": "群主", "789012": "管理员", "345678": "管理员"}`

> 💡 配合 AstrBot 的 Function Calling 功能，AI 可以自动查询群内管理信息，实现“乖巧”或“配合”的行为。

## 🔧 工作机制

1. **监听群消息**：检查该群是否被黑白名单允许、是否已在缓存中。
2. **缓存缺失时**：调用 QQ API 获取群成员列表，仅缓存 `role` 为 `owner`（群主）或 `admin`（管理员）的用户。
3. **LLM 请求前钩子**：
   - 按身份等级 `bot管理员 > 群主 > 管理员 > 普通成员` 判定发送者身份（bot管理员优先于群内身份）。
   - 根据身份选择对应提示词模板，将 `{昵称}` 替换为发送者的群昵称，然后**追加**到 LLM 的 `system_prompt` 末尾（模板留空则不追加）。
4. **工具函数**：提供身份查询能力，供 AI 在对话中主动调用。

## 🐛 常见问题

| 问题 | 解决 |
|------|------|
| 提示词没有生效 | 检查 `黑白名单` 是否允许该群；确认缓存是否已刷新；确认对应身份的提示词模板未留空 |
| 群主/管理员身份没识别 | 使用 `/刷新管理员缓存` 手动更新；确认机器人是否有获取群成员列表的权限 |
| 私聊中 LLM 工具调用失败 | 工具函数仅适用于群聊，私聊会返回提示 |
